# Backvog — Backlog 相当のプロジェクト管理システム（モックアップ）

[Backlog](https://backlog.com/ja/) と同等の機能構成を持つプロジェクト管理システムのモックアップです。
ビルド不要の静的 HTML / CSS / JavaScript のみで構成されており、`index.html` をブラウザで開くだけで動作します。

## 起動方法

```bash
# ファイルを直接開く
open backlog/index.html

# もしくは簡易サーバー経由（推奨）
python3 -m http.server 8000
# → http://localhost:8000/backlog/
```

## 実際に動作する機能

モックアップですが、以下はクライアントサイドで実際に動作し、`localStorage` に保存されます。

- 課題の新規登録（課題キーは `FOCUS-35` から自動採番）
- 状態・優先度・担当者・カテゴリー・マイルストーン・開始日／期限日・工数の変更
- 変更時の更新履歴の自動記録（「状態: 未対応 → 処理中」のように記録）
- コメントの投稿（状態変更との同時登録に対応）
- ボードのドラッグ＆ドロップによる状態変更
- Wiki ページの編集・新規作成
- 課題一覧の絞り込み・並び替え・ページング、横断検索
- お知らせの既読化
- データのエクスポート（JSON）／初期化（スペース設定 → データ管理）

## ファイル構成

```
backlog/
├── index.html      画面一覧（ここから各画面へ）
├── backlog.css     共通テーマ（CSS変数で配色を一括変更）
├── data.js         サンプルデータ + localStorage ストア（PM）
├── app.js          共通UI・ユーティリティ（PMUI）
└── 01〜16_*.html   各画面
```

### データモデル（`data.js`）

| 種別 | 内容 |
| --- | --- |
| 状態 | 未対応 / 処理中 / 処理済み / 完了 |
| 優先度 | 高 / 中 / 低 |
| 種別 | タスク / バグ / 要望 / その他 |
| マイルストーン | v1.0 リリース / v1.1 機能改善 / v2.0 不妊治療領域 |
| カテゴリー | フロントエンド / バックエンド / インフラ / デザイン / ドキュメント / 調査 |
| 課題 | 34 件のサンプル（コメント・更新履歴つき） |

サンプルデータは、同リポジトリの Focus（患者管理システム）開発プロジェクトを題材にしています。

### カスタマイズ

配色は `backlog.css` 冒頭の CSS 変数を変更するだけで全画面に反映されます。

```css
:root {
  --pm-primary: #42bc72;   /* メインカラー */
  --pm-nav-bg:  #262f3d;   /* サイドバー背景 */
  --pm-bg:      #f2f4f6;   /* 画面背景 */
}
```

共通のヘッダー・サイドバーは `app.js` の `PMUI.mount('<画面キー>')` が各画面へ差し込みます。
新しい画面を追加する場合は、`<div id="pm-header"></div>` と `<div id="pm-side"></div>` を置き、
`data.js` → `app.js` の順に読み込んで `PMUI.mount()` を呼び出してください。
