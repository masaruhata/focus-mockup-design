Backvog
Backlog 相当のプロジェクト管理システム — モックアップ
全 16 画面 ・ 課題の登録／状態変更／コメントは実際に動作します
データはブラウザの localStorage に保存されます（初期化はこちら）

このモックアップについて

  • 実際に動く機能: 課題の追加 / 状態・優先度・担当者・期限の変更 / コメント投稿 / ボードのドラッグ＆ドロップ / Wiki の編集 / 絞り込み・並び替え・ページング / 横断検索
  • データ: data.js のサンプルデータを起点に、変更内容を localStorage（キー: pm_mock_db_v1）へ保存
  • 配色の変更: backlog.css 冒頭の CSS 変数（--pm-primary など）を書き換えると全画面へ反映されます
  • 共通UI: ヘッダーとサイドバーは app.js の PMUI.mount() が各画面へ差し込みます
  • ビルド不要: すべて静的 HTML / CSS / JavaScript。ファイルをブラウザで開くだけで動作します
